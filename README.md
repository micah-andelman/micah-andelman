#### How I build

I'm a hardware person first. I design the systems, pick the parts, wire and test them on real hardware, and decide how the software should work. Most of the code itself is written with AI ([Claude Code](https://claude.com/claude-code)), and commits it helped with say so. What I bring is knowing what to build, specifying it precisely, and checking that it actually works on the bench.
